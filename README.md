# WakeMac

<img src="Assets/AppIcon.png" width="128" alt="WakeMac icon">

原生 macOS 菜单栏应用，管理保活、合盖运行与自动收尾。无需安装 Amphetamine 或 Power Protect。采用 SwiftUI / AppKit 构建，浅色界面使用系统字体、克莱因蓝主题与白、黑、橙黄辅助色。方形状态开关、平直按钮与菜单共享组件，动效尊重系统“减少动态效果”。界面目前为简体中文。

## 使用

点菜单栏图标选择模式，或在 Applications 双击 WakeMac 打开主窗口。主窗口默认以 1000×680 的横向内容尺寸打开「工作模式」页（小屏幕按可用区域调整），可自由缩放；主窗口和菜单栏面板均可直接切换「保持唤醒」与「合盖继续运行」，并显示实际回读状态及合盖服务授权入口。

开启合盖运行会同时保持唤醒；关闭合盖运行后仍保持桌面唤醒。关闭保持唤醒会一起结束合盖运行，恢复正常休眠。

- **后台工作**：原生保活会话、允许屏幕熄灭，通过自带的合盖服务开启全局防休眠。屏幕按系统当前闲置时间关闭。用于通风桌面，不要在包中持续高负载运行。
- **桌面工作**：原生 IOKit 保活、允许熄屏，不开启全局防休眠。上盖打开时保持运行；密码要求采用所选锁屏策略；已经锁定时需要本人或 macOS 支持的方式解锁。默认不模拟鼠标移动；不会自动解锁。
- **正常休眠**：释放 WakeMac 的保活断言和合盖会话、按所选策略核验密码要求。恢复合盖休眠；不终止其他应用。其他应用仍可能阻止闲置睡眠。
- **立即休眠**：先核验正常模式，再向 macOS 发出休眠请求。如果锁屏设置未完成，只提示设置，不在稍后突然自动休眠；完成设置后再点一次。

## 认证与权限

桌面工作通过 IOKit 电源断言实现，无需管理员或自动化授权。默认不申请辅助功能权限；只有显式开启轻移鼠标时需要授权。不申请屏幕录制权限，不读取或保存 Mac 密码。

偏好设置提供“要求即时密码保护”，默认开启：系统已关闭或延迟密码要求时，工作模式会等待用户完成即时保护设置。关闭此项后，三个模式跟随 macOS 已有的密码要求，允许延迟或不要求密码；状态不可读取时仍不标记为已核验。按钮可直接打开系统锁屏设置，必要认证由用户在系统界面完成。WakeMac 不修改密码要求、不读取或保存登录密码、不解锁已经锁定的 Mac。系统设为不要求密码时，熄屏后返回桌面无需输入密码，这不是解锁已锁定的会话。

合盖运行使用应用内置的签名辅助服务，通过 Apple 的 `SMAppService` 登记，由用户在系统设置中批准。服务仅提供开启/关闭合盖会话与续期接口，内部执行固定的 `pmset -a disablesleep 0/1`，不接受命令、路径或任意参数，不修改 sudoers。XPC 通信要求同一 Apple 开发者签名及指定程序标识。

服务通过 IOKit 观测电池／接电切换；仅持有有效租约时，在切换后的 20 秒窗口内修复系统清除的防休眠开关并核验。窗口内无法区分系统重置与其他程序同期关闭；需要停止保活时请在 WakeMac 结束工作。稳定或未知电源、无租约或超时均不会自动重设。

退出前恢复正常模式；重启不重放旧命令或定时。主程序退出或断线后服务释放合盖会话；主程序每 5 秒独立续租，状态读取不会阻塞续租；没有心跳时 30 秒到期，监测每 3 秒执行一次。服务崩溃后由 launchd 重启，使用 root 所有的记录恢复它自己开启的防休眠；恢复失败会重试。IOKit 保活断言由系统随主程序退出释放。

## 环境要求

仅支持 Apple Silicon（M 系列）与 macOS 15+，不支持 Intel 或 macOS 14；Release 构建只生成 arm64。构建需要 Xcode 26+（macOS 26 SDK）和 Swift 6 工具链。Swift Package 无第三方库依赖。

## 启用合盖运行

1. 将签名的 `WakeMac.app` 放进 Applications 并打开。
2. 在「工作模式」页或菜单栏面板点击「启用服务…」。
3. 在系统设置的「通用 → 登录项与扩展」批准 WakeMac 的后台服务。系统可能要求管理员认证。
4. 返回 WakeMac 选择「后台工作」。

桌面工作、日期选择、命令任务和运行记录不需要这项授权。移除服务前，应用会先恢复正常休眠。若从旧版升级，请先在旧版或其他保活应用中恢复休眠；WakeMac 不接管或修改其他程序的保活会话。

## 从源码构建

```sh
git clone https://github.com/OrxHsu/WakeMac.git
cd WakeMac
```

```sh
swift test --scratch-path /tmp/wakemac-build
scripts/build-app.sh
```

构建产物默认为 `/tmp/wakemac-dist/WakeMac.app`，复制到 Applications 后打开；再次打开应用可显示状态面板。默认使用 ad hoc 签名，仅供本机构建。合盖服务需要主程序和辅助程序使用同一 Apple 开发者证书签名（Apple Development 或 Developer ID）；可通过 `WAKEMAC_SIGN_IDENTITY` 指定自己的证书。未签名或 ad hoc 构建仅可使用无需合盖服务的功能。`WAKEMAC_BUILD_DIR` 与 `WAKEMAC_OUTPUT_DIR` 可覆盖构建和输出路径。当前未提供公证安装包。

自动测试覆盖状态协调、失败处理、命令生命周期、日期选择、辅助服务租约与原生保活断言，并含不需要管理员权限的桌面/正常模式运行检查。本机已验证签名服务登记与系统批准、后台/正常切换、客户端断线恢复，以及暂停客户端后 30–33 秒的超时恢复（包括释放主程序原生保活）。本机真实合盖连续采样超过 2 分钟，期间系统防休眠保持开启，采样持续执行。持有租约时强制终止辅助服务的实机检查已通过：launchd 重启后移除服务记录并关闭系统防休眠，主程序释放自己的保活断言；首次观测到服务重启后约 1 秒内完成清理，之后可重新开启并结束会话。不同机型仍需分别验证。

合盖运行使用系统的 `SleepDisabled` 开关，`disablesleep` 不是 Apple 文档保证长期兼容的公开参数；每次切换都读取系统状态核验，失败不会显示为已启用。

## 原生功能

“工作会话”是一段有结束条件的保持唤醒时间，例如保持运行 1 小时、等某个应用或进程退出、等下载完成。满足条件后结束保活并恢复正常休眠，不关闭应用或终止进程。Safari 下载监测用于下载大文件时保持 Mac 运行，完成后自动收尾；需要用户选择正在下载的文件或 `.download` 包，不会监控浏览记录或接管 Safari 下载。

「工作模式 / 工作会话 / 自动触发 / 自动收尾 / 命令任务 / 偏好设置 / 主题外观 / 运行记录」统一使用原生控件与 Liquid Glass。

- **工作会话**：无限期、1 分钟至 7 天、指定结束时间、指定应用退出、下载文件完成。应用按实际包身份核验；增加指定后台进程退出与定时会话延长。进程按当前用户、PID 和启动时间监测，防止同名重启或 PID 复用误判；下载需观察增长并达到自定义稳定时长，临时文件还需完成重命名。系统为所选文件发布可判定进度时显示百分比，不读取 Safari 的私有元数据。暂停下载可能被当作稳定，重要传输请手动结束。
- **会话效果**：独立显示器保活、延后屏保、解锁期间轻移鼠标、磁盘定期访问。屏保保活也会延后显示器休眠；所有效果随正常模式、核验丢失和退出释放。鼠标功能每次启动默认关闭，仅显式点击时申请辅助功能权限；可设置移动间隔、闲置起始及停止阈值。使用原生指针移动，不模拟键盘输入、不重置系统闲置计时；显示器和屏保防休眠由各自开关控制。可指定应用作为自动屏保例外。
- **磁盘保活**：在用户选择的目录按可配置间隔创建、同步并删除一个 1 字节临时文件；不阻止弹出，不保证磁盘控制器永不休眠。不访问未选择的目录。
- **闲置策略**：工作期间按自定义时间请求熄屏锁定或启动系统屏保，不修改认证要求；默认关闭。
- **自动触发**：外接屏、镜像、USB、蓝牙、应用运行/前台、充电/电量、电源连接/断开、IP、Wi-Fi、Cisco VPN、DNS、耳机/音频输出、挂载磁盘、CPU、闲置时间、每周时间表及后台进程。可组合全部或任一条件，保存、编辑和启停，另有总开关。每周时间表按当前时区的当地时间处理跨午夜和夏令时；规则可单独覆盖显示器及屏保行为。新规则默认关闭。规则每 5 秒采样，未知状态不会匹配。手动操作及定时/低电量结束优先，条件解除后规则才重新触发。
- **权限与可观测性**：Wi-Fi 名称和已配对蓝牙设备需要系统授权，仅显式按钮请求。未公开系统 VPN 状态的 Cisco 客户端显示未知；USB/蓝牙耳机用指定音频输出识别。应用选择器和当前设备建议避免手填标识。
- **外观与通知**：内置或自定义菜单栏图标、结束时间/剩余时间、12/24 小时制、短于 30 秒的自定义通知声音。已拒绝通知时，开启按钮直接打开通知设置；回到应用会刷新权限状态。
- **AppleScript**：通过应用自带 scripting dictionary 开始、结束和延长会话，查询剩余时间与状态，控制显示器、屏保、合盖、触发器及磁盘保活。临时显示／屏保和合盖调整保留正在运行的会话期限，不修改未来会话默认设置。所有脚本动作走相同核验与收尾。

```applescript
tell application "WakeMac"
    start session mode "desktop" for minutes 30
    session status
    extend session for minutes 15
    session time remaining
    prevent display sleep
    allow display sleep
    end session
end tell
```

`mode` 支持 `desktop` 和 `background`；省略 `for minutes` 为无限期。脚本与界面均采用偏好设置中的锁屏策略，不修改系统认证设置。功能清单参考 [Amphetamine 官方介绍](https://apps.apple.com/us/app/amphetamine/id937984704)；[Power Protect](https://github.com/x74353/Amphetamine-Power-Protect) 主要修复 Apple Silicon 合盖期间电源切换问题，WakeMac 使用已有签名服务和租约实现相应电源控制。

## 自动收尾与快捷操作

点击面板设置按钮打开主窗口，包含工作模式、会话、自动触发、自动收尾、命令、设置、主题外观、记录八页。

- **定时恢复**：在工作模式下选择 30 分钟、1 小时、2 小时或指定日期时间。到点恢复正常模式，允许合盖休眠；不强制立刻休眠，也不终止命令。面板显示最近的倒计时，取消按钮只取消当前显示的那一项。切到正常模式会取消定时。
- **低电量保护**：默认开启、20% 阈值，可调整为 5%–50%。电池供电时提前 5% 提醒，到达阈值后给予 60 秒取消时间，再核验正常模式和锁屏保护并请求休眠。接电、无法读取电源状态或取消操作会阻止对应休眠；实际发出请求前再次读取电源。取消后当前工作会话不重复触发，重新选工作模式恢复保护。
- **任务成功后休眠**：输入工作目录及一条非交互 zsh 命令，点“运行，成功后休眠”。未在工作模式时先进入桌面工作；命令退出码为 0 后倒计时 60 秒，失败则记录并通知。手动切模式或取消完成后休眠会撤销这次自动休眠，命令继续运行。退出应用会提示等待命令结束，防止丢失管理中的任务。
- **命令边界**：只跟踪本应用启动的前台 shell；不要使用 `&`、`nohup` 或需要密码输入的命令。不推断其他 Codex 任务是否结束，不重放旧命令。输出日志前 5 MB 保存在本机 `~/Library/Application Support/WorkModes/Task Logs/`，截断会在记录中注明；日志可能含命令输出中的敏感信息，请自行注意输入。命令内容本身不会写入事件历史。
- **菜单栏**：默认显示模式及剩余分钟，可以在设置中关闭文字，保留原折月图标。
- **记录**：保存最近 200 条模式、定时、任务、错误及系统休眠/唤醒记录。合盖/开盖、内屏状态约 10 秒采样，记录观测结果，不推断未观测到的断线原因。位置为 `~/Library/Application Support/WorkModes/history.json`。
- **快捷键**：默认 `⌃⌥1` 后台、`⌃⌥2` 桌面、`⌃⌥3` 正常。新增会话启停、显示／屏保切换、合盖切换、延长会话、打开面板及开始定时／无限期会话，新增操作默认关闭。设置页可更换修饰键、数字/字母，或关闭。重复和系统占用会显示错误，修改失败保留原配置。无需辅助功能权限。
- **系统通知**：在设置点“开启系统通知…”并允许 macOS 通知；未允许时仍在面板和记录中显示状态。关闭通知不关闭倒计时保护。

重启应用会恢复正常模式并丢弃未完成的倒计时，不会在登录时突然休眠或重新执行旧命令。可显式启用“启动后／唤醒后开始新会话”，使用单独设置的默认时长，不恢复旧命令、应用、进程或下载任务。

0.4.0 还提供会话开始／结束／触发通知、自动清理本应用已显示的通知、延长提示音、定期会话提醒、合盖提示音及可选本机统计。提示音只调整自身播放音量，不修改系统音量；统计不上传。详细功能对应与验证边界见 [FEATURES.md](FEATURES.md)。
